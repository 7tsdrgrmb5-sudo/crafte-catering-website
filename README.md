# CraftE Catering LLC Website

Static, mobile-first website for CraftE Catering LLC.

## Included
- Luxury black + metallic-gold visual system
- Original CraftE logo asset
- Responsive navigation and mobile layout
- Services, packages, booking process, service area and FAQ sections
- Quote-request form that opens a prefilled email to `craftecateringllc@gmail.com`
- Instagram, email and phone contact links
- SEO description + local business structured data
- No framework or build step required

## Run locally
Open `index.html` directly in a browser, or serve the folder with any static web server.

## GitHub Pages
Once this repository exists on GitHub:
1. Push these files to the default branch.
2. Open **Settings → Pages**.
3. Under **Build and deployment**, choose **Deploy from a branch**.
4. Select the default branch and `/ (root)`.
5. Save.

## Files
- `index.html` — page content and structure
- `styles.css` — all styling and responsive behavior
- `script.js` — mobile navigation, reveal animations and quote-email generation
- `assets/gold_cc_monogram_catering_logo.png` — CraftE logo

## Notes
The current site presents CraftE's standard service model as client-supplied alcohol, mixers and sufficient ice, with CraftE providing shopping guidance. Update alcohol-inclusive language only when the appropriate licensing/authorization is in place.
